# Mindustry 모드 설치

## 1. 아래 글자를 복사하세요

칸 오른쪽의 **복사 버튼(📋)** 을 누르세요. 버튼이 안 보이면 글자를 길게 눌러 복사하세요.

```
gsm1478g9-cell/factory-sim-mod
```

## 2. 게임에서 붙여넣기

1. Mindustry를 켜고 **모드 → 모드 가져오기 → GitHub에서 모드 가져오기** 를 누르세요.
2. 입력 칸을 **길게 눌러 붙여넣기** 하고 확인을 누르세요.
3. 다운로드가 끝나면 게임을 **완전히 껐다가** 다시 켜세요. (최근 앱 목록에서 위로 밀어서 끄기)

## 3. 잘 깔렸는지 확인

맵에 들어갔을 때 오른쪽 위 점수판에 **"활동 점수 ○ / 50점"** 이 보이면 성공이에요.

오류 창이 뜨면 화면을 그대로 두고 손을 들어 선생님께 알려주세요.
