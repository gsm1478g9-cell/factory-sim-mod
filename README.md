# Mindustry 모드 설치

## 1. 아래 글자를 복사하세요

칸 오른쪽의 **복사 버튼(📋)** 을 누르세요. 버튼이 안 보이면 글자를 길게 눌러 복사하세요.

```
gsm1478g9-cell/factory-sim-mod
```

## 2. 게임에서 붙여넣기

1. Mindustry를 켜고 **모드 → 모드 가져오기 → GitHub에서 모드 가져오기** 를 누르세요.
2. 입력 칸을 **길게 눌러 붙여넣기** 하고 확인을 누르세요.
3. 다운로드가 끝나면 게임을 **완전히 껐다가** 다시 켜세요. (최근 앱 목록에서 위로 밀어서 끄기)

## 3. 잘 깔렸는지 확인

게임 첫 화면에 **별 모양 [수행평가] 버튼**이 보이면 성공이에요. 모드 목록에서 Mindustry Assessment 버전이 **0.5**인지도 확인하세요.

- 이미 설치했다면: **모드 → Mindustry Assessment → [재설치]** → 게임을 완전히 껐다 켜기
- 수행평가는 **[수행평가] 버튼**으로만 시작하고 이어서 해요. 점수판도 이 게임에서만 나와요.
- 수업이 끝나기 전 점수판의 **[점수 코드] → [복사하기]** → 학습지 맨 아래 칸에 붙여넣고 제출해요.

오류 창이 뜨면 화면을 그대로 두고 손을 들어 선생님께 알려주세요.
